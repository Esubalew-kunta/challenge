# Team onboarding in 45 minutes

## 1. Explain the boundary

Show what Claude can read, edit, and run in the approved project. Explain that generated work and tool output still require verification.

## 2. Show the shared system

Open `CLAUDE.md`, one rule, and one skill. Explain why each belongs in that location. Show `/memory`, `/permissions`, plan mode, and how to interrupt work.

## 3. Practice one safe task

Use a real low risk task. Ask for a plan, review the proposed action, approve only understood steps, and verify the result with evidence.

## 4. Practice one refusal

Give a task outside the approved scope. The user should recognize the risk, stop, and request the correct owner or permission.

## 5. Practice a handoff

Run `/team-handoff`. Another teammate should understand the result, evidence, remaining risk, and next owner without reopening the full conversation.

Onboarding is complete when the person can work safely, explain the controls, and produce a clear handoff.
