# Second Brain and memory

Use the right place for each kind of knowledge.

## `CLAUDE.md`

This is shared project guidance. Put stable commands, architecture facts, standards, safety boundaries, and the definition of done here. Keep it concise so important instructions remain visible.

## Auto memory and `MEMORY.md`

Claude Code version 2.1.59 or later can maintain auto memory. It is on by default and stored locally for each project. Its `MEMORY.md` is a short index, with detail moved to topic files. It is not automatically shared with teammates.

Run `/memory` to see loaded instructions, inspect saved memory, and turn auto memory on or off. Audit it because remembered information can become outdated.

## Simple weekly routine

1. Open `/memory`.
2. Remove incorrect or temporary notes.
3. Move stable team facts into `CLAUDE.md`.
4. Turn a repeated procedure into a skill.
5. Never store passwords, tokens, private customer data, or secrets.

Official reference: https://code.claude.com/docs/en/memory
