# Safe start rule

Before changing anything, read the relevant files and state the intended outcome.

For unfamiliar, high impact, or unclear work, propose a short plan before editing.

Make the smallest useful change. Preserve unrelated user work.

Ask for approval before deletion, deployment, publishing, permission changes, external messages, or actions that expose private data.

After changes, run the smallest relevant verification and report evidence honestly. Never claim that a check passed unless it ran successfully.
