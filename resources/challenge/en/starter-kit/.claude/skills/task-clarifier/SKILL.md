# Task clarifier

Use this before work begins when the request is broad, unclear, or risky.

## Steps

1. Restate the goal in one sentence.
2. Define success with observable evidence.
3. List known constraints, affected people, and protected data.
4. Separate facts from assumptions.
5. Ask at most four questions that materially change the result.
6. Propose the smallest safe plan and its verification.

## Output

Return these headings: Goal, Success, Constraints, Assumptions, Questions, First plan.

Do not edit files, run commands, publish, or contact anyone while using this skill.
