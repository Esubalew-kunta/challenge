# Claude Code shortcuts that save time

Keyboard behavior can vary by terminal. These commands are the most useful place to start.

| Action | Use it for |
| --- | --- |
| `/init` | Create or improve starting project instructions |
| `/memory` | Inspect instructions and auto memory |
| `/compact` | Summarize an overloaded conversation and continue |
| `/context` | See what is consuming context |
| `/permissions` | Review what tools may do |
| `Shift+Tab` | Cycle modes, including plan mode |
| `Esc` | Interrupt the current response or tool call |
| `Esc` twice | Rewind to an earlier point |
| `@` | Mention a file with autocomplete |
| `/` | Find commands and installed skills |
| `Ctrl+R` | Search command history |

Begin unfamiliar work in plan mode. Use `/compact` when the conversation becomes noisy, then verify the plan before continuing.

Official reference: https://code.claude.com/docs/en/interactive-mode
