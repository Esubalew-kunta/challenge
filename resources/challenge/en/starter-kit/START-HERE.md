# Day 10 Starter Kit

Build a useful Claude Code system in 15 minutes. No API setup or paid integration is required.

## Your result

You will finish with:

1. A clear `CLAUDE.md` for your project
2. A safe rule that asks for evidence before risky work
3. A reusable `/task-clarifier` skill
4. A simple memory routine
5. A setup score that shows your next improvement

## Choose your pace

Beginner: follow every step in `INSTALL.md`.

Comfortable: replace the example commands and project map with your real ones.

Advanced: keep the small foundation, then add only rules and skills that remove repeated work.

## First win

Copy the kit into a practice project. Run `/task-clarifier` with one real task, review its plan, then complete the setup score.

Your selected category pack adds three job specific skills. Keep only the category you chose.
