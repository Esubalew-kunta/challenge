# Install in 15 minutes

## 1. Make a safe practice copy

Start in a project that uses version control. Save or commit current work first.

## 2. Add project instructions

Copy `CLAUDE-TEMPLATE.md` to the project root and rename the copy `CLAUDE.md`. Replace every bracketed prompt with a short, true answer.

## 3. Add the ready tools

Copy the included `.claude` folder into the project root. Keep its folder structure.

If your selected category pack also contains `.claude`, merge its `skills` folder into this one. Do not replace skills with the same name until you inspect both versions.

## 4. Check what Claude loaded

Start Claude Code inside the project. Run `/memory`, confirm the project instructions, then run `/task-clarifier` with one small task.

## 5. Stay in control

Use plan mode for unfamiliar or risky work. Review proposed commands and file changes before approval. Never paste secrets into project instructions or memory.

Finish with `SETUP-SCORE.md` and improve the lowest scoring item.
