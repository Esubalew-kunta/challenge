# Start here

This is a simple workspace for turning loose notes into clear next actions. It works with Claude Code, VS Code, Cursor, Obsidian, or any normal text editor. Obsidian is optional.

You do not need to understand every folder before you begin. Start with one note and one useful outcome.

## 5 minute setup

1. Copy this folder somewhere easy to find.
2. Rename it `My-Claude-Workspace` if you want a personal name.
3. Open the folder in your preferred editor.
4. Open `00_Index.md` and write your main focus for today.
5. Put one unfinished thought in `00-Inbox/QUICK-CAPTURE.md`.

If you use Claude Code, open it from this folder. Type `/memory` to inspect the separate auto memory system and its settings. The `MEMORY.md` in this folder is your manual notebook.

## Your first prompt

Copy this into Claude Code or another assistant:

```text
Read CLAUDE.md, MEMORY.md, 00_Index.md, and my quick capture. Help me choose one useful next action. Do not edit anything until I approve the action.
```

## The simple daily flow

1. Capture thoughts in `00-Inbox/`.
2. Choose one focus in `00_Index.md`.
3. Move active work into `01-Projects/`.
4. Save reusable knowledge in `02-Resources/`.
5. Record durable decisions in `MEMORY.md`.
6. Run the short checklist in `03-Routines/DAILY-RESET.md`.

Use `/weekly-review` when you want Claude Code to guide the weekly review skill included in this workspace.

## Where each thing belongs

- `00-Inbox/`: unsorted ideas, requests, and notes.
- `01-Projects/`: work with a clear outcome and next action.
- `02-Resources/`: references and knowledge worth finding again.
- `03-Routines/`: checklists you repeat.
- `04-Archive/`: finished or inactive material.
- `MEMORY.md`: decisions and preferences you maintain manually.

## Safety note

The instructions and rule in this workspace guide Claude. They are not a hard security control. Review proposed actions, keep credentials out of notes, and ask before anything is deleted, sent, published, or installed.
