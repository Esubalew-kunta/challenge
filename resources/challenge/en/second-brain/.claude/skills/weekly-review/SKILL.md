# Weekly review

Review the workspace without changing any file.

## Read

1. Read `00_Index.md`.
2. Read the notes in `00-Inbox/`.
3. Read each active file in `01-Projects/`.
4. Read `MEMORY.md` and the weekly review checklist.

## Report

Return these five short sections:

1. Workspace health: what is clear, missing, duplicated, or stale.
2. Inbox decisions: where each captured item should go and why.
3. Project status: outcome, blocker, and one next action per active project.
4. Memory check: decisions to keep, review, or remove.
5. Next week: one main focus and up to three supporting actions.

Separate facts from recommendations. If information is missing, label the gap instead of guessing.

Do not edit, move, archive, or delete anything. End by asking which proposed updates the user wants applied.
