# Control context and cost

More context is not automatically better. Relevant context produces better decisions than a large pile of files.

## Before a session

State one outcome, point to the few relevant files, list constraints, and define proof of completion.

## During a session

Use `/context` to see what consumes space. Start a focused session when the topic changes. Use `/compact` when the history is useful but noisy. Put repeated reference material in a skill so it loads only when needed.

## Before a large task

Ask for a plan and verification first. Break independent outcomes into smaller tasks. Avoid repeatedly reading the same large files without a reason.

## Simple signal

After each task, rate context quality from 1 to 5.

1 means the task wandered and reread unrelated material.

5 means the task used focused evidence and reached a verified result.

Improve the prompt and project map before buying or connecting more tools.
