# Connect external tools safely

This kit works without an AI API, MCP server, or paid integration.

Connect a service only when a repeated workflow needs current external data or an external action.

## Connection checklist

1. Verify the owner, source, maintenance status, and license.
2. Inspect the requested permissions and all executable code.
3. Start with read only access and the smallest data scope.
4. Keep secrets out of repositories, prompts, skills, and memory.
5. Test with non sensitive data in a limited project.
6. Keep publishing, deletion, payments, and permission changes behind human approval.
7. Record the owner, purpose, review date, and removal steps.
8. Remove access when the connection no longer creates value.

Permission rules reduce risk but do not replace review. Never approve a command you do not understand.

Official reference: https://code.claude.com/docs/en/permissions
