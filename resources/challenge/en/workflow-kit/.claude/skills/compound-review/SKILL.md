# Compound review

Use this only after a real task has been completed.

## Inputs

Ask for the intended outcome, work performed, verification evidence, friction, mistakes, and user feedback. Mark missing evidence clearly.

## Review

1. Compare the intended outcome with the evidence.
2. Identify the largest repeated cost or avoidable risk.
3. Separate a one time issue from a reusable pattern.
4. Recommend one improvement only.
5. Choose its home: `CLAUDE.md`, rule, skill, hook, MCP, or ordinary documentation.
6. Define a measure for the next run.

## Output

Return: Result, Evidence, Repeated friction, One improvement, Correct home, Safety boundary, Next measure.

Do not modify the system until the user accepts the recommendation.
