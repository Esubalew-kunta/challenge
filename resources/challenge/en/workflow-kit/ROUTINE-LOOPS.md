# Ready routine loops

Copy one loop into your working notes. Keep it until evidence shows a better version.

## Build loop

1. Plan one observable outcome.
2. Build the smallest useful change.
3. Verify the result and check unintended effects.
4. Capture one stable learning for reuse.

## Debug loop

1. Observe the exact failure.
2. Reproduce it consistently.
3. Reduce it to the smallest failing case.
4. Form one testable cause.
5. Fix the cause and rerun the evidence.
6. Capture the diagnostic only if it will help again.

## Content loop

1. Confirm the audience, problem, and desired action.
2. Build one source of truth.
3. Adapt it to each channel without inventing claims.
4. Review clarity, accuracy, and response.
5. Save the pattern that performed well.

## Weekly improvement loop

Review one completed task, one repeated friction, one avoidable mistake, and one reusable win. Improve only the highest value item next week.
