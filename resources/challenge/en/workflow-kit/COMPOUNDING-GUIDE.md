# Improve your skills through use

A compounding system gets better from proven work, not from collecting the most tools.

## The second time rule

When you repeat a useful multi step prompt for the second time, consider turning it into a skill.

## Improvement ladder

1. Save the successful inputs and expected output.
2. Separate required steps from optional advice.
3. Add safety limits and a clear stopping point.
4. Add one realistic example.
5. Test on a different task in the same category.
6. Keep evidence of what improved.
7. Remove instructions that create noise or unreliable results.

## Quality check

A strong skill has one clear purpose, explains when to use it, requests the needed input, produces a predictable structure, protects risky actions, and stays small enough to inspect.

Review trusted external skills before installation. Copy useful principles, but respect licenses and never assume popularity equals safety.
