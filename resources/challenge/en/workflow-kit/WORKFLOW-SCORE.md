# Five minute workflow score

Give yourself one point for each yes.

1. The workflow starts with one observable outcome.
2. Inputs and owners are clear.
3. Human judgment points are named.
4. Risky actions require approval.
5. Verification uses real evidence.
6. Context stays focused.
7. Repeated work has one reusable aid.
8. The aid is stored in the correct tool.
9. Old instructions have a review date or owner.
10. The next run can show whether the system improved.

0 to 4: simplify the workflow before automating.

5 to 7: useful system. Fix the weakest control.

8 to 10: compounding system. Improve one measured friction point at a time.
