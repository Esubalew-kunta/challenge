# Day 20 Workflow Kit

Turn useful work into a system that becomes easier and more reliable each time.

## The compounding loop

Plan the smallest useful outcome. Build it with clear boundaries. Verify it with evidence. Capture only the learning worth reusing.

Plan, build, verify, capture.

## Start in 20 minutes

1. Choose one task you have completed at least twice.
2. Fill in `WORKFLOW-REVIEW.md` using real evidence.
3. Run `/compound-review` to find one reusable improvement.
4. Use `DECISION-GUIDE.md` to place it in the right tool.
5. Calculate `WORKFLOW-SCORE.md` before adding more complexity.

The goal is not more configuration. The goal is less repeated thinking, fewer mistakes, and clearer proof of completion.
