# Install

Copy the included `.claude/skills` folder into a project root. Start Claude Code there and type `/skills` to confirm the three Founder skills appear.

For use across projects, copy each skill folder into `~/.claude/skills/`. Restart Claude Code if you created the main skills folder during the open session.

No package manager, plugin, script, account, or paid integration is required.

Keep private customer, employee, investor, and financial information inside an authorized project. Remove identifying details when they are not needed for the decision.
