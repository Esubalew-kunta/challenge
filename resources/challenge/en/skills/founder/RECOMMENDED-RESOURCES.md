# Recommended resources for Founders

Start with the AIMakers validation, decision, and weekly review skills. Add a larger workflow only when you will use it repeatedly.

## GStack route

Consider office-hours for demand questions, CEO review for strategic challenge, and autoplan when an approved idea needs a full execution plan.

## Vercel route

When the company is improving a website, consider writing guidelines and web design guidelines. Technical deployment skills should remain with an authorized technical owner.

Superpowers is useful when the team wants a disciplined build process with discovery, planning, tests, and review.
