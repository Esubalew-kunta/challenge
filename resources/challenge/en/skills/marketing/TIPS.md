# Tips

## Compound marketing learning

Connect each campaign choice to a result. When the same message, audience, claim, or measurement problem returns, improve the relevant skill with one reusable check.

1. Save the original brief and hypothesis.
2. Preserve approved source material.
3. Record target, actual result, and data limits.
4. Name one learning that could change the next campaign.
5. Add one tested improvement to the relevant skill.

Put stable brand rules and approved terminology in `CLAUDE.md`. Put repeatable planning and review methods in skills. Keep campaign facts and audience data in the authorized project.

More content is not automatically more learning. A clear hypothesis, clean source, and honest review create better compounding.
