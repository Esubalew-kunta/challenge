# Install

Copy the included `.claude/skills` folder into a project root. Start Claude Code there and type `/skills` to confirm the three Marketing skills appear.

For use across projects, copy each skill folder into `~/.claude/skills/`. Restart Claude Code if the main skills folder was created during the current session.

No package manager, plugin, script, account, or paid integration is required.

Keep embargoed plans, audience data, customer details, and unapproved claims inside the authorized project. Review every output before publishing it.
