# Content repurposer

Create useful adaptations from a supplied source truth. Repurposing is not permission to create new claims.

## Establish the source

Identify the approved source, core idea, supporting facts, approved quotes, audience, goal, brand voice, channels, format limits, and call to action.

## Adapt

For each channel:

1. Name the audience moment and purpose.
2. Choose one relevant message from the source.
3. Adapt the hook, structure, length, and language to the channel.
4. Preserve the original meaning and evidence level.
5. Include the approved call to action when appropriate.
6. Note the source section supporting each factual claim.
7. Mark any required visual, link, caption, or accessibility text.

Do not invent facts, quotes, results, urgency, customer stories, or product capabilities. If the source cannot support a requested angle, explain the gap and suggest a safer angle.
