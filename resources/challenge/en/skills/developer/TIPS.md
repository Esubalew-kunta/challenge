# Tips

## Compound what you learn

After each use, check which instruction produced a useful result and which one caused confusion. When the same correction appears a second time, improve the relevant skill so the next session starts smarter.

Use this short loop:

1. Run the skill on a real task.
2. Review the result and evidence.
3. Record one repeated mistake or missing check.
4. Make one change at a time in the skill.
5. Run it again on a similar task.

## Put knowledge in the right place

- Put durable project facts and commands in `CLAUDE.md`.
- Put a repeatable procedure in a skill.
- Put temporary task details in the prompt.
- Put long, optional guidance in a reference file linked by the skill.

## Keep skills strong

- Give each skill one clear job.
- Keep the main file under 100 lines when possible.
- Make the description name real trigger situations.
- Require evidence for claims about code.
- Keep risky actions behind explicit permission.
- Test a skill with both an easy example and a difficult example.

Do not add every preference to every skill. More text can make the important rules harder to follow.
