# Developer Skills Pack

Three focused skills help you understand code, change it carefully, and review it before release. They work with local files and normal Claude Code permissions. No paid integration is required.

## Choose one

- Use `/codebase-mapper` when you need to understand where a feature starts, how data moves, or where a change belongs.
- Use `/safe-change` when you know the desired behavior and want the smallest tested implementation.
- Use `/code-reviewer` when a change is complete and you want concrete defects and missing tests found before release.

## Beginner path

1. Start with `/codebase-mapper` and name one feature you want to understand.
2. Use `/safe-change` for one small bug or behavior.
3. Finish with `/code-reviewer` before you share the result.

## Builder path

Invoke the skill that matches the current stage. Add the target path, expected behavior, constraints, and verification command to your prompt.

These skills require explicit invocation. Type the skill name when you want it. This keeps unexpected edits and reviews from starting automatically.

Read `INSTALL.md` once, then open `EXAMPLES.md` and copy the closest prompt.
