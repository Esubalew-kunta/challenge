# Recommended resources for Developers

Start with the three AIMakers skills in this pack. Add an external system only when a repeated problem justifies the extra setup.

## GStack route

Start with planning through `plan-eng-review`, investigation, QA, code review, and ship. GStack is integrated, so follow its official setup instead of copying isolated folders.

## Vercel route

For relevant web projects, consider React best practices, composition patterns, web interface guidelines, and Vercel optimization. Install from the official Vercel repository only after reviewing the selected skills.

Use React Native or view transition guidance only when the project actually needs it.
