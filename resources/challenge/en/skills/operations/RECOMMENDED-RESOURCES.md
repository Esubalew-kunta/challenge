# Recommended resources for Operations

Start with the AIMakers SOP, audit, and reporting skills. Keep live system changes behind explicit approval.

## GStack route

Consider guard for safer work boundaries, health for checks, canary for post release monitoring, and investigation for root cause analysis.

GStack can register hooks and change configuration during setup. Inspect it before installation and test it away from critical operations.

Use Wshobson only when a specific operational domain needs a specialized plugin and an owner can review it.
