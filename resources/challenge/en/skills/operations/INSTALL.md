# Install

Copy the included `.claude/skills` folder into one project root. Start Claude Code there and type `/skills` to confirm the three Operations skills appear.

For personal use across projects, copy each skill folder into `~/.claude/skills/`. Restart Claude Code if the top level skills folder was created during the current session.

No package manager, plugin, script, account, or paid integration is required.

Keep real credentials, customer records, and private incident details out of skill files. Store authorized operational evidence only inside the correct protected project.
