# Examples

## Beginner

```text
/sop-builder Turn these notes into a simple returns SOP. Mark any missing owner, access, exception, or completion check instead of guessing.
```

```text
/process-auditor Audit this approval process for delays, repeated work, failure points, and weak controls. Recommend one small experiment. Do not change the process.
```

```text
/weekly-operations-report Create this week's report from the supplied updates. Separate facts from interpretation and show every missing metric.
```

## Builder

```text
/sop-builder Create a controlled onboarding SOP with role boundaries, decision paths, escalation, recovery, evidence, and a quarterly review owner.
```

```text
/process-auditor Map cycle time, handoffs, rework, failure modes, and controls. Rank improvements by evidence, impact, effort, and operational risk.
```

```text
/weekly-operations-report Build a leadership report with service health, period comparison, incident learning, risk movement, decisions needed, and next week evidence.
```
