# Install

## One client project

Copy the included `.claude/skills` folder into the project root. Start Claude Code there and type `/skills` to confirm all three Consultant skills appear.

If the top level skills folder was created during an open session, restart Claude Code once.

## Every project

Copy each skill folder into `~/.claude/skills/` in your home folder. Keep client facts out of personal skill files. Client facts belong in the authorized project only.

No package manager, plugin, script, account, or paid integration is required.

These skills use normal Claude Code permissions. Review source notes for confidential information before sharing any result.
