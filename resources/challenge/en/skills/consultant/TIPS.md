# Tips

## Compound your consulting system

After each engagement, record which discovery question changed a decision, which proposal section caused confusion, and which action format improved follow through. When a correction repeats, update the relevant skill once.

1. Use a skill on real authorized material.
2. Ask the client or team what was unclear.
3. Separate a one client fact from a reusable method.
4. Add only the reusable method to the skill.
5. Test the change on a different example.

Keep client facts inside the client project. Put stable working preferences in `CLAUDE.md` and repeatable methods in skills.

Strong consulting output distinguishes evidence, inference, recommendation, and commitment. Never let polished wording hide an unknown.
