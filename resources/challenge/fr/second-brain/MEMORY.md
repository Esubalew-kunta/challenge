# Mémoire manuelle de l'espace

Ce fichier est un carnet manuel que vous entretenez. Ce n'est pas la mémoire automatique de Claude Code.

La mémoire automatique de Claude Code est conservée séparément pour chaque projet dans un dossier local à la machine. Utilisez `/memory` dans Claude Code pour la consulter, la modifier ou la désactiver. Elle peut retenir des préférences et des corrections utiles, mais vous devez relire ce qu'elle conserve.

Utilisez ce fichier pour les informations qui doivent rester visibles et voyager avec cet espace. Gardez-le court. Supprimez ce qui n'est plus vrai.
