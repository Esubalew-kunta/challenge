# Archives

Placez ici les éléments terminés ou inactifs afin de garder les dossiers actifs lisibles.

Avant l'archivage :

1. Confirmer que le travail est terminé ou volontairement en pause.
2. Noter toute décision durable dans `MEMORY.md`.
3. Déplacer les connaissances réutilisables dans `02-Resources/`.
4. Ajouter la date d'archivage en haut du fichier.

Archiver ne veut pas dire supprimer. Relisez les anciens éléments avant de les effacer définitivement.
