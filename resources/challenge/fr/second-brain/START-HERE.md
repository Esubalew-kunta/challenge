# Commencer ici

Cet espace transforme des notes éparses en prochaines actions claires. Il fonctionne avec Claude Code, VS Code, Cursor, Obsidian ou un éditeur de texte classique. Obsidian est facultatif.

Vous n'avez pas besoin de comprendre chaque dossier avant de commencer. Partez d'une seule note et cherchez un résultat utile.

## Installation en 5 minutes

1. Copiez ce dossier dans un emplacement facile à retrouver.
2. Renommez-le `Mon-Espace-Claude` si vous voulez un nom personnel.
3. Ouvrez le dossier dans votre éditeur préféré.
4. Ouvrez `00_Index.md` et écrivez votre priorité du jour.
5. Placez une idée inachevée dans `00-Inbox/QUICK-CAPTURE.md`.

Si vous utilisez Claude Code, ouvrez-le depuis ce dossier. Tapez `/memory` pour consulter le système de mémoire automatique séparé et ses réglages. Le fichier `MEMORY.md` de ce dossier est votre carnet manuel.

## Votre premier prompt

Copiez ce texte dans Claude Code ou un autre assistant :

```text
Lis CLAUDE.md, MEMORY.md, 00_Index.md et ma capture rapide. Aide-moi à choisir une prochaine action utile. Ne modifie rien avant que je valide cette action.
```

## Le flux quotidien simple

1. Capturez les idées dans `00-Inbox/`.
2. Choisissez une priorité dans `00_Index.md`.
3. Placez le travail actif dans `01-Projects/`.
4. Conservez les connaissances réutilisables dans `02-Resources/`.
5. Notez les décisions durables dans `MEMORY.md`.
6. Suivez la courte liste dans `03-Routines/DAILY-RESET.md`.

Utilisez `/weekly-review` pour demander à Claude Code de guider la compétence de revue hebdomadaire incluse dans cet espace.

## Où ranger chaque élément

- `00-Inbox/` : idées, demandes et notes non triées.
- `01-Projects/` : travail avec un résultat et une prochaine action.
- `02-Resources/` : références et connaissances à retrouver facilement.
- `03-Routines/` : listes de contrôle répétées.
- `04-Archive/` : éléments terminés ou inactifs.
- `MEMORY.md` : décisions et préférences entretenues manuellement.

## Note de sécurité

Les instructions et la règle de cet espace guident Claude. Elles ne remplacent pas un vrai contrôle de sécurité. Relisez les actions proposées, ne conservez aucun identifiant secret et demandez une validation avant toute suppression, tout envoi, toute publication ou toute installation.
