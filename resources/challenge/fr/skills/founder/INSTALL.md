# Installation

Copiez le dossier `.claude/skills` inclus dans la racine d'un projet. Lancez Claude Code à cet endroit et tapez `/skills` pour vérifier que les trois skills Fondateur apparaissent.

Pour tous vos projets, copiez chaque dossier de skill dans `~/.claude/skills/`. Redémarrez Claude Code si vous avez créé le dossier principal des skills pendant la session ouverte.

Aucun gestionnaire de paquets, plugin, script, compte ou service payant n'est nécessaire.

Gardez les informations privées des clients, salariés, investisseurs et finances dans un projet autorisé. Retirez les détails identifiants lorsqu'ils ne servent pas la décision.
