# Ressources recommandées pour les Fondateurs

Commencez par les skills AIMakers de validation, décision et revue. Ajoutez un grand système uniquement pour un usage répété.

## Parcours GStack

Considérez office-hours pour les questions de demande, CEO review pour le défi stratégique et autoplan lorsqu'une idée approuvée exige un plan complet.

## Parcours Vercel

Pour améliorer un site web, considérez writing guidelines et web design guidelines. Les skills techniques de déploiement restent sous la responsabilité d'une personne autorisée.

Superpowers convient à une équipe qui veut une construction disciplinée avec découverte, plan, tests et revue.
