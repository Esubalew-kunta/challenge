# Installation

## Un projet client

Copiez le dossier `.claude/skills` inclus dans la racine du projet. Lancez Claude Code à cet endroit et tapez `/skills` pour vérifier que les trois skills Consultant apparaissent.

Si le dossier principal des skills a été créé pendant une session ouverte, redémarrez Claude Code une fois.

## Tous les projets

Copiez chaque dossier de skill dans `~/.claude/skills/` dans votre dossier personnel. Ne placez jamais de faits client dans un skill personnel. Ces faits restent dans le projet autorisé.

Aucun gestionnaire de paquets, plugin, script, compte ou service payant n'est nécessaire.

Ces skills utilisent les permissions normales de Claude Code. Vérifiez les informations confidentielles avant tout partage du résultat.
