# Ressources recommandées pour les Consultants

Commencez par les skills AIMakers de découverte, proposition et plan d'action. Gardez les faits client dans le projet autorisé.

## Parcours GStack

Considérez office-hours pour clarifier le problème, design consultation pour améliorer la solution et document generation pour les livrables.

## Parcours Anthropic

Les skills de documents Anthropic peuvent aider pour les PDF, documents Word, tableaux et présentations. Vérifiez la licence de chaque skill et la permission du client.

Utilisez Wshobson uniquement pour découvrir un plugin documentaire ou métier précis après inspection.
