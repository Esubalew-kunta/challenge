# Ressources recommandées pour les Développeurs

Commencez avec les trois skills AIMakers de ce pack. Ajoutez un système externe uniquement lorsqu'un problème répété justifie la configuration supplémentaire.

## Parcours GStack

Commencez par `plan-eng-review`, investigation, QA, code review et ship. GStack forme un ensemble intégré. Suivez son installation officielle au lieu de copier des dossiers isolés.

## Parcours Vercel

Pour un projet web pertinent, considérez React best practices, composition patterns, web interface guidelines et Vercel optimization. Installez depuis le dépôt officiel après inspection.

Utilisez React Native ou view transitions uniquement lorsque le projet le demande réellement.
