# Pack de skills Développeur

Trois skills ciblés vous aident à comprendre le code, le modifier avec prudence et le relire avant publication. Ils utilisent les fichiers locaux et les permissions normales de Claude Code. Aucune intégration payante n'est nécessaire.

## Choisissez selon le besoin

- Utilisez `/codebase-mapper` pour comprendre le départ d'une fonction, le flux des données ou la place d'une modification.
- Utilisez `/safe-change` lorsque le comportement attendu est clair et que vous voulez la plus petite mise en œuvre testée.
- Utilisez `/code-reviewer` lorsque le changement est terminé et que vous voulez trouver les défauts concrets et les tests manquants.

## Parcours débutant

1. Commencez avec `/codebase-mapper` et nommez une seule fonction à comprendre.
2. Utilisez `/safe-change` pour un petit bug ou un comportement précis.
3. Terminez avec `/code-reviewer` avant de partager le résultat.

## Parcours builder

Lancez le skill adapté à l'étape actuelle. Ajoutez dans votre prompt le chemin cible, le comportement attendu, les contraintes et la commande de vérification.

Ces skills exigent un lancement explicite. Tapez leur nom lorsque vous les voulez. Cela évite le démarrage automatique d'une modification ou d'une revue inattendue.

Lisez `INSTALL.md` une fois, puis ouvrez `EXAMPLES.md` et copiez le prompt le plus proche de votre besoin.
