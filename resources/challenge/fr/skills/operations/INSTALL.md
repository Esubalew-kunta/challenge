# Installation

Copiez le dossier `.claude/skills` inclus dans la racine d'un projet. Lancez Claude Code à cet endroit et tapez `/skills` pour vérifier que les trois skills Opérations apparaissent.

Pour une utilisation personnelle, copiez chaque dossier de skill dans `~/.claude/skills/`. Redémarrez Claude Code si le dossier principal des skills a été créé pendant la session actuelle.

Aucun gestionnaire de paquets, plugin, script, compte ou service payant n'est nécessaire.

Ne placez aucun identifiant réel, dossier client ou détail privé d'incident dans les skills. Gardez les preuves autorisées dans le projet protégé concerné.
