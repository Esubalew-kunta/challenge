# Conseils

## Capitaliser sur la connaissance opérationnelle

Après chaque exécution réelle, comparez le processus écrit avec ce qui s'est produit. Lorsqu'une même exception ou correction revient, améliorez le skill ou la procédure avec un seul changement testé.

1. Observer le processus actuel.
2. Noter les preuves et les variations.
3. Trouver un manque répété.
4. Faire une modification contrôlée.
5. Mesurer le résultat avant de la généraliser.

Placez les règles opérationnelles stables dans `CLAUDE.md`, les méthodes répétables dans les skills et les détails du processus dans le projet protégé.

N'automatisez pas un mauvais processus uniquement parce qu'il se répète. Clarifiez d'abord les responsabilités, retirez les étapes inutiles et sécurisez les accès.
