# Installation

Copiez le dossier `.claude/skills` inclus dans la racine d'un projet. Lancez Claude Code à cet endroit et tapez `/skills` pour vérifier que les trois skills Marketing apparaissent.

Pour tous vos projets, copiez chaque dossier de skill dans `~/.claude/skills/`. Redémarrez Claude Code si le dossier principal des skills a été créé pendant la session actuelle.

Aucun gestionnaire de paquets, plugin, script, compte ou service payant n'est nécessaire.

Gardez les projets sous embargo, données de public, informations client et affirmations non approuvées dans le projet autorisé. Relisez chaque résultat avant publication.
