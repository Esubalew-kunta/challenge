# Score de configuration en deux minutes

Donnez vous un point pour chaque oui.

1. Le résultat du projet est il clair dans `CLAUDE.md` ?
2. Les vraies commandes d'exécution, de test et de contrôle sont elles écrites ?
3. La carte du projet est elle correcte ?
4. Les actions risquées sont elles clairement listées ?
5. La définition de terminé est elle vérifiable ?
6. Pouvez vous lancer `/task-clarifier` ?
7. Avez vous vérifié `/memory` ?
8. Avez vous essayé une petite tâche en mode plan ?

## Votre résultat

0 à 3 : base à construire. Faites `INSTALL.md` une fois.

4 à 6 : démarrage utile. Corrigez le point le plus faible avant d'ajouter des outils.

7 à 8 : prêt à capitaliser. Utilisez le système pendant une semaine, puis transformez le premier flux répété en skill.
