# Second Brain et mémoire

Placez chaque connaissance au bon endroit.

## `CLAUDE.md`

Ce sont les instructions partagées du projet. Ajoutez les commandes stables, les faits d'architecture, les standards, les limites de sécurité et la définition de terminé. Restez concis pour garder les informations importantes visibles.

## Mémoire automatique et `MEMORY.md`

Claude Code version 2.1.59 ou plus récente peut maintenir une mémoire automatique. Elle est active par défaut et stockée localement pour chaque projet. Son fichier `MEMORY.md` sert d'index court, avec les détails placés dans des fichiers thématiques. Cette mémoire n'est pas partagée automatiquement avec l'équipe.

Lancez `/memory` pour voir les instructions chargées, inspecter la mémoire et l'activer ou la désactiver. Vérifiez la mémoire car une information peut devenir ancienne.

## Routine hebdomadaire simple

1. Ouvrez `/memory`.
2. Supprimez les notes incorrectes ou temporaires.
3. Déplacez les faits stables de l'équipe vers `CLAUDE.md`.
4. Transformez une procédure répétée en skill.
5. Ne stockez jamais de mot de passe, jeton, donnée client privée ou secret.

Référence officielle : https://code.claude.com/docs/en/memory
