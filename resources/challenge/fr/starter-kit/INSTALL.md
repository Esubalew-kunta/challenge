# Installation en 15 minutes

## 1. Créez une copie de travail sûre

Commencez dans un projet suivi par un gestionnaire de versions. Sauvegardez ou validez le travail actuel.

## 2. Ajoutez les instructions du projet

Copiez `CLAUDE-TEMPLATE.md` à la racine du projet et renommez la copie `CLAUDE.md`. Remplacez chaque texte entre crochets par une réponse courte et vraie.

## 3. Ajoutez les outils prêts à l'emploi

Copiez le dossier `.claude` inclus à la racine du projet. Gardez sa structure.

Si votre pack de catégorie contient aussi `.claude`, fusionnez son dossier `skills` avec celui ci. Ne remplacez jamais une skill de même nom avant d'avoir comparé les deux versions.

## 4. Vérifiez ce que Claude a chargé

Démarrez Claude Code dans le projet. Lancez `/memory`, confirmez les instructions chargées, puis utilisez `/task-clarifier` avec une petite tâche.

## 5. Gardez le contrôle

Utilisez le mode plan pour un travail nouveau ou risqué. Vérifiez les commandes et fichiers proposés avant approbation. Ne placez jamais de secrets dans les instructions ou la mémoire.

Terminez avec `SETUP-SCORE.md` et améliorez le point le plus faible.
