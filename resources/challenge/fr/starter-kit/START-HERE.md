# Kit de démarrage du jour 10

Créez un système Claude Code utile en 15 minutes. Aucune API ni intégration payante n'est nécessaire.

## Votre résultat

Vous terminerez avec :

1. Un `CLAUDE.md` clair pour votre projet
2. Une règle sûre qui demande des preuves avant un travail risqué
3. Une skill `/task-clarifier` réutilisable
4. Une routine de mémoire simple
5. Un score de configuration qui montre la prochaine amélioration

## Choisissez votre rythme

Débutant : suivez chaque étape de `INSTALL.md`.

À l'aise : remplacez les commandes et la carte du projet par les vraies informations.

Avancé : gardez cette petite base, puis ajoutez seulement les règles et skills qui suppriment un travail répétitif.

## Premier résultat

Copiez le kit dans un projet d'essai. Lancez `/task-clarifier` avec une tâche réelle, vérifiez son plan, puis calculez votre score.

Votre pack de catégorie ajoute trois skills adaptées à votre métier. Gardez seulement la catégorie choisie.
