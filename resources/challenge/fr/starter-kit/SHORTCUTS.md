# Raccourcis Claude Code utiles

Le comportement du clavier varie selon le terminal. Commencez avec ces commandes.

| Action | Utilité |
| --- | --- |
| `/init` | Créer ou améliorer les instructions du projet |
| `/memory` | Inspecter les instructions et la mémoire automatique |
| `/compact` | Résumer une conversation chargée et continuer |
| `/context` | Voir ce qui consomme le contexte |
| `/permissions` | Vérifier les actions autorisées |
| `Shift+Tab` | Parcourir les modes, dont le mode plan |
| `Esc` | Interrompre la réponse ou l'outil en cours |
| `Esc` deux fois | Revenir à un point antérieur |
| `@` | Mentionner un fichier avec autocomplétion |
| `/` | Trouver les commandes et skills installées |
| `Ctrl+R` | Rechercher dans l'historique |

Commencez les travaux nouveaux en mode plan. Utilisez `/compact` quand la conversation devient confuse, puis vérifiez le plan avant de continuer.

Référence officielle : https://code.claude.com/docs/en/interactive-mode
