# Checklist de sécurité de l'entreprise

Complétez la avant le pilote et après un changement important de périmètre.

## Données

1. Classifiez les données autorisées dans le projet.
2. Excluez les identifiants, données réglementées, secrets client et données personnelles inutiles.
3. Confirmez les exigences de conservation, journalisation et suppression.

## Accès et permissions

1. Donnez à chaque utilisateur et connexion le plus petit accès nécessaire.
2. Préférez la lecture seule pour le premier pilote.
3. Gardez les règles de refus plus fortes que les règles de confort.
4. Vérifiez les paramètres du projet et `/permissions` avec le responsable sécurité.

## Ressources externes

1. Vérifiez le propriétaire, la source, la licence, la maintenance et les permissions demandées.
2. Inspectez les skills, plugins, hooks, scripts et serveurs MCP avant utilisation.
3. Testez tout nouveau code exécutable dans un environnement isolé sans donnée sensible.

## Approbation humaine

Exigez la pour toute publication, suppression, paiement, modification de production, changement d'accès, message client, engagement juridique et déplacement de donnée sensible.

## Préparation aux incidents

Notez qui peut révoquer l'accès, où l'activité est vérifiée, comment signaler un incident et comment retirer les éléments concernés.
