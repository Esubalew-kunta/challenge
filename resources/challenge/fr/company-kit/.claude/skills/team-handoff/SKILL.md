# Transmission d'équipe

Utilisez cette skill quand le travail passe à une autre personne, session ou équipe.

## Rassembler

Collectez le résultat demandé, les changements ou décisions réels, les preuves de vérification, les approbations, le travail ouvert, les risques connus et les fichiers utiles. Signalez clairement les faits manquants.

## Vérifier

1. Séparez le travail terminé du travail prévu.
2. Ne dites jamais qu'un contrôle a réussi sans preuve.
3. Nommez les actions qui demandent encore une approbation humaine.
4. Identifiez la prochaine petite action sûre.
5. Nommez le prochain responsable ou indiquez qu'il est inconnu.
6. Ajoutez une condition d'arrêt en cas de nouveau risque ou périmètre.

## Résultat

Retournez : Résultat, Terminé, Preuve, Non terminé, Risques, Approbations, Prochaine action, Prochain responsable, Condition d'arrêt, Références.

N'exposez aucun secret ni donnée personnelle inutile dans la transmission.
